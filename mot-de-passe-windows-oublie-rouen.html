Mot de passe Windows oublié ou compte bloqué ?

Cette intervention s’adresse aux particuliers, indépendants et petites structures qui ne parviennent plus à accéder à une session Windows.

Mot de passe Windows oublié

Vous ne vous souvenez plus du mot de passe utilisé pour ouvrir votre session.

PIN Windows oublié ou refusé

Le code PIN habituel n’est plus accepté ou vous ne le retrouvez plus.

Compte Windows bloqué

Votre compte ne vous permet plus d’accéder normalement au bureau Windows.

Session Windows inaccessible

Vous restez bloqué sur l’écran de connexion et avez besoin d’une assistance sur place.

Intervention autour de Rouen : Grand-Quevilly, Rouen, l’axe jusqu’à Tôtes et Tourville-la-Rivière, selon les disponibilités.

Tarif particulier

60 € / h TTC à domicile

Le tarif applicable et le créneau sont confirmés avant l’intervention.
